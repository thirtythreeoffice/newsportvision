# Deploying newsportvision

The site is a static build. `python3 build.py` writes everything the host
serves into `dist/`; there is no Node, no package manager, and no dependency
beyond the Python standard library.

    python3 build.py            # dist/ for Netlify or any plain static host
    python3 build.py --vercel   # dist/ for Vercel, and vercel.json at the root
    python3 build.py --serve    # build, then read it on http://127.0.0.1:8080

## Vercel

`vercel.json` is generated by the build, not written by hand, so the redirects
and headers can never drift from the ones the site is built with. It carries:

* **228 redirect rules** — every legacy Wix URL, in both locales, spelled with
  and without a trailing slash. Vercel normalises the trailing slash before it
  reads these rules, so a bare `/shop` is answered `308 -> /shop/` and then
  `301 -> /products/`: two hops, both permanent, query strings preserved. Every
  one of the 114 URLs was followed on the live deployment and lands on its
  page.
* **Security headers** on every response, including a Content-Security-Policy
  whose `script-src` pins the one inline script by SHA-256 hash. If that script
  ever changes, the build recomputes the hash; nothing has to be remembered.
* **`/assets/*` cached for a year, immutable.** Every asset URL carries a
  content hash, so a changed file is a changed URL.
* **HTML revalidated on every visit**, so a deploy is visible at once.
* **`trailingSlash: true`** — the canonical form of every route here.

An unknown URL answers 404 with the English page, in both trees: Vercel serves
one `404.html` for the whole deployment and has no per-directory equivalent.

Import the repository at <https://vercel.com/new>. The build settings come
from `vercel.json` (Framework: Other, Build Command: `python3 build.py
--vercel`, Output Directory: `dist`), so there is nothing to fill in.

`dist/` is committed. That is deliberate: if the build step ever fails on the
host, clearing the Build Command in the project settings deploys the committed
output exactly as it is.

### The domain

Add the domain under Project → Settings → Domains, then point the DNS at
Vercel. Vercel issues the certificate and redirects `www` to the apex (or the
other way round) once both are added.

## Netlify

`netlify.toml` and `dist/_redirects` / `dist/_headers` say the same things in
Netlify's dialect. Either drag `dist/` onto <https://app.netlify.com/drop>, or
connect the repository and let it run `python3 build.py`.
